# Threads 洞察擷取器 v1.2

1. 解壓縮資料夾。
2. Chrome 開啟 `chrome://extensions/`。
3. 開啟「開發人員模式」→「載入未封裝項目」→ 選本資料夾。
4. 到 `https://www.threads.com/insights?hl=zh-tw`，打開某一篇貼文的洞察詳情。
5. 按擴充套件「① 擷取／累積目前貼文洞察」。換下一篇可重複此步驟。
6. 全部抓完後切回社群效益 Dashboard 的「資料中心」，按「② 全部送入目前 Dashboard」。

單篇詳細頁會嘗試保存：瀏覽次數、個人檔案瀏覽次數、瀏覽人數、追蹤次數、按讚率、回覆率、分享率、引用率、轉發率，以及首頁／搜尋／個人檔案／活動頁籤的瀏覽來源占比。

它只讀目前頁面已載入的 DOM，不讀密碼、Cookie 或 Access Token。
